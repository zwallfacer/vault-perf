Returns are time-weighted. Per-period returns are chained over Hyperliquid's pnlHistory, which already excludes deposits and withdrawals. Naive equity growth is not return — on a funded vault it can read several hundred percent while the trading return is a few percent.

Net P&L is the realised dollar result over the same window as the other columns — net of fees and funding, with deposits and withdrawals excluded. It is a total rather than a rate, so it survives where the annualised columns cannot: it never divides by an equity figure. A large P&L on a large vault is not the same achievement as the same figure on a small one — read it against TVL, not on its own.

TVL rank is not a performance rank. The table is ordered by TVL because that is what buoy publishes directly; sort by any other column to rank on performance instead.
